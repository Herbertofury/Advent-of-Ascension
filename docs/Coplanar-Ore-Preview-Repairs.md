# Coplanar Ore Preview Repairs

**60 inventory previews across 34 atlas sheets corrected: 30 in 1.16.5 and 30 in 1.21.1.** The affected released models put a cutout ore texture directly over an equal-position host-rock cube. The earlier documentation rasterizer kept only the first face at an equal depth, hiding ore markings. This was a documentation-rendering bug, not evidence that the game displays plain rock.

## What changed

- The repair accepts only the exact two-cube layout, equal vertex positions, matching face UVs and binary-alpha overlay textures.
- Opaque overlay pixels replace the matching host pixels; transparent overlay pixels retain the host. The resulting single-surface reference avoids the equal-depth ambiguity.
- The original JARs and game assets are unchanged. These are source-derived static reference renders with documentation lighting.
- All 60 corresponding searchable inventory cards and 34 atlas sheets use the corrected images. Counts and candidate identities are unchanged.
- This is a bounded adapter, not a general claim of shader, semitransparent or animated render parity.
