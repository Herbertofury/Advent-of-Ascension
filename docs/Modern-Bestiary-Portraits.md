# Illustrated modern bestiary: all 83 inspected entries

**Minecraft 1.21.1 / AoA 3.7.16.1 resources, pinned 1.21 source registrations.** Every entry in this inspected living-entity roster now has a source-mapped static portrait. This is roster coverage, not a claim that every entity in the entire game or every runtime appearance is documented.

[Open the searchable bestiary](https://herbertofury.github.io/Advent-of-Ascension/bestiary-explorer.html?v=1.21.1) for base attributes, spawn evidence, illustrated loot and exact creature links.

## Variant and state previews

- Charger: ten registered source appearances, with Plains as the default portrait.
- Veloraptor: Green and Brown; Green is the source default.
- Dryad Sprite: six registered source appearances, with Wood as the default portrait.
- Opteryx: adult-model and egg-state resources.
- Fish: eleven explicit alternate-model/texture joins complete the shared-geometry forms.
- Shiny Squid: nine-part neutral body-layer reconstruction from source, using the released texture. Runtime tentacle motion, body rotations and fullbright lighting are not reproduced.

Expand **Source appearances** on the relevant creature card. Alternate skins are not separate registered mobs. Selection predicates and animation remain separate evidence.
