# Legacy 1.16.5 model showcases

Rendered documentation images from pinned official 1.16.5 source model constructors and official AoA 3.6.11 textures. Models and textures by Tslat and contributors. These are independent static showcases, not Enderloom runtime screenshots. Full PNGs retain detail; WebP thumbnails keep wiki pages light. Source/runtime differences and unrendered classes remain explicitly tracked in the galleries.
