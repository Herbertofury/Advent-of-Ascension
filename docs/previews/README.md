# AoA visual previews

Rendered documentation showcases of official Advent of Ascension models and textures, created by Tslat and contributors. These are preview images, not reusable source asset packs or a playable conversion.

Each gallery identifies the exact source release. Static rest poses do not demonstrate animations, AI, spawning, or Enderloom runtime parity. Generated-item previews retain their actual pixel-art shape; they are not invented volumetric redesigns.
