Why this result?

The selector compares displayed levels, requires at least 15, and keeps the first skill at the lowest eligible level. It returns no target when no eligible level is below 1000.

The XP request uses the effective level capped at 100. It calculates the next-level XP lookup, then divides by the crystal's divisor. This is not necessarily a fixed fraction of a vanity level.

The crystal passes the fourth XP-helper flag as true, but the inspected helper does not read that flag. Do not assume XP bonuses are ignored.
