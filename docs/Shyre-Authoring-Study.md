# Shyre Blaster: reproducible authoring study

This is editable original fantasy-prop source for Blender 4.3.2. It is not a Minecraft mod, a TaCZ gunpack, or an accepted finished weapon. The [published concept and original behavior](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Shyre-Blaster-Weapon-Profile) remain the reference.

## Rebuild and check

From this extracted folder, run:

- `blender -b -t 2 --python-exit-code 1 --python build-v7.py -- --no-render`
- `blender -b -t 2 --python-exit-code 1 --python inspect_v8.py -- --no-render`
- `blender -b -t 2 --python-exit-code 1 --python check_geometry.py -- v8`
- `blender -b -t 2 --python-exit-code 1 --python check_inspect_group.py`

Omit `--no-render` to produce the corresponding still. `render_inspect_v8.py` renders all 70 authored frames at 24 fps. It requires the v8 scene, generated by the commands above. NumPy is used by the clearance helper and is available in the tested Blender runtime.

## Known-bad regression control

Build `build-v4.py` with the same `--no-render` option, then run `check_geometry.py -- v4`. That check must return a nonzero exit and identify the six defective objects. Do not use that scene as production source.

## What passed

All 31 visible evaluated meshes pass finite-coordinate, non-degenerate-face, closure and positive-volume checks. The earlier v4 scene failed on six objects; the corrected construction repairs winding and constrains thin-part bevel width without shrinking the grip.

The crystal and two orbit curves have one animated owner. Over frames 1–70, a conservative sphere envelope derived from the scale control points stays at least 0.15643 scene units from the checked static geometry. The test rejects a deliberately intersecting placement. It does not validate hands, native transformations, attachment variants or the complete weapon animation set.

## Still open

The prop is a partial visual blockout. Material richness, faithful sculptural detail, full hand animation, equip/aim/fire/optional-loading states, audio and combat effects, baking, export, gameplay and native performance are unfinished. The supplied clip is labeled Blender authoring footage. No acceptance gate may be promoted merely because these narrow checks pass.

Only the useful current source and checks are packaged. Earlier local studies remain retained separately; the mottled gold material candidate was not selected.

## Portable material and web-export study

[Open the current authoring preview](https://herbertofury.github.io/Advent-of-Ascension/shyre-authoring-preview.html) · [Download reproducible v11 source and checks](https://raw.githubusercontent.com/Herbertofury/Advent-of-Ascension/main/docs/shyre-authoring-export-source-v11.zip).

The v11 study adds stepped medallion trim, diamond inlay seats and a reverse crown seam caught by opposite-side review. A 1024-pixel static-body atlas retains base color and tangent-space normals. A diffuse-only albedo bake was rejected because it darkened metallic gold; the corrected bake uses the actual base-color input through emission. The clean rebuild produces byte-identical base-color and normal images.

The web GLB contains 51 meshes, two embedded images and one cosmetic inspection action. Exact bake triangles, UVs and corner normals are retained, with explicit tangents. The official Khronos validator reports zero errors, warnings, informational notices or hints. The separate export contract rejects missing tangents and verifies the single crystal owner with two orbit children. UV checks cover 12,900 triangles without positive-area overlaps above 1e-10.

These are scoped format and authoring checks. The cloud review browser cannot create a WebGL context, so its 3D rendering is not visually accepted. The page provides a rendered v11 still and a clearly labeled earlier v8 inspection video when WebGL is unavailable. Full native, artistic and hand-animation gates remain open.
