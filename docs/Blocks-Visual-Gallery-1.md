# Blocks Visual Gallery 1

[Visual atlas](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Visual-Atlas) · [Coverage and limitations](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Render-Coverage)

Advent of Ascension models/textures by **Tslat and contributors**. These are independently rendered documentation showcases from **AoA 3.7.16.1 / Minecraft 1.21.1**, not Enderloom runtime screenshots. [Official mod](https://modrinth.com/mod/adventofascension) · [Official wiki](https://adventofascension.fandom.com/wiki/Advent_of_Ascension_Wiki).

Models retain their actual geometry. Flat/generated items are shown as their pixel-art item model; runtime tint, custom rendering and alternate block states require separate validation. Click a sheet to enlarge it.
