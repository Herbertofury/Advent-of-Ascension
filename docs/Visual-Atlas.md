# Visual Atlas

**The mod, in view.** Actual models and textures, named and version-labelled.

Advent of Ascension models/textures by **Tslat and contributors**. These are independently rendered documentation showcases from **AoA 3.7.16.1 / Minecraft 1.21.1**, not Enderloom runtime screenshots. ## Interactive 3D

A standalone local-JAR Model Observatory is being tested. It is separate from GitHub wiki Markdown, which displays the static/animated preview images. Interactive geometry inspection must not be confused with in-game rendering or a completed converted mod.

## Every historical version

The first visual pass uses 1.21.1 / 3.7.16.1. The downloaded 1.20.1, 1.16.5 and 1.12.2 releases are the next source sets for generation-specific galleries. An older source model is never silently relabelled as a modern implementation.
