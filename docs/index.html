Scope & credits

Advent of Ascension models and artwork are by Tslat and contributors. This independent viewer contains no AoA source assets. Models remain in your browser memory.

This edition supports Bedrock/GeckoLib cuboid geometry and texture selection. It shows static rest poses. CPU fallback uses unlit textures and triangle-depth sorting; intersecting transparent geometry may differ from the game. Rendering sleeps when the view is idle. Java-coded legacy models, animation expressions, custom rendering layers and item/block JSON need their own adapters. A resource in a JAR does not prove it is playable or implemented by Enderloom.
