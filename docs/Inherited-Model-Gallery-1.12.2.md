# Inherited biped models · 1.12.2

Twenty-eight additional NPC/creature presentations resolve inherited geometry that the literal AoA-only importer could not reconstruct. The vanilla ModelBiped constructor was symbolically decoded from the official Minecraft 1.12.2 client using Forge MCPConfig class mappings. AoA supplies the explicit renderer-to-texture assignments. Thin-biped limb replacements are taken from its own constructor.

[Constructor provenance](https://github.com/Herbertofury/Advent-of-Ascension/blob/main/docs/vanilla-constructor-provenance.json) · [1.12.2 entity atlas](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Entity-Atlas-1.12.2)

No game code was executed. These are constructor-rest documentation portraits, without held equipment, attack/flight animations or runtime scaling. AoA textures and designs by Tslat and contributors; vanilla base geometry by Mojang. Click a portrait for the full-size image.
