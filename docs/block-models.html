What this preview represents

Static inventory item-model geometry, not a placed-block state or guarantee of in-game availability. Block-entity animation, fluids, game lighting, biome tint and other runtime rendering are not reproduced. Animated source textures use the first declared frame. This software canvas preview uses approximate face ordering. Intersecting and translucent surfaces can differ from game rendering. A source-sheet fallback is shown if canvas rendering is unavailable.

Original AoA models and textures by Tslat and contributors. This documentation viewer runs its own rendering code; it does not execute Minecraft or mod code.
