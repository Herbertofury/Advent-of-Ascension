What this preview represents

Independent placed-plant resource states, not an assembled tall plant, natural-state guarantee or growth simulation. Growth timing, world lighting, collision, harvesting and gameplay behavior are not simulated. Animated source textures use the first declared frame. This software canvas preview uses approximate face ordering. Intersecting and translucent surfaces can differ from game rendering. A source-sheet fallback is shown if canvas rendering is unavailable.

Original AoA models and textures by Tslat and contributors. This documentation viewer runs its own rendering code; it does not execute Minecraft or mod code.
