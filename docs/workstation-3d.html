What this preview represents

Static inventory item-model geometry, not a running machine or placed-block state. Block-entity animation, pistons, fluids, game lighting and other runtime rendering are not reproduced. Animated source textures use the first declared frame. A software canvas preview is used when WebGL is unavailable; its face ordering is approximate. A source-sheet fallback is shown if neither renderer is available.

Original AoA models and textures by Tslat and contributors. This documentation viewer runs its own rendering code; it does not execute Minecraft or mod code.
