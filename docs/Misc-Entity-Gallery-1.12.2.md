# Miscellaneous entities and renderer variants · 1.12.2

Thirty-five additional presentations resolve miscellaneous/eggless registrations, renderer method references and a conditional default model. They include five Automaton colors, tablet entities, stones, clones, Gyrocopter, Meganeuropsis, Runicorn and Tree Spirit. These are not 35 new distinct mobs.

Registry IDs come from explicit registration calls, including `newMiscEntityEntry` and `newEgglessEntry`. Literal constructor geometry and official AoA 3.3.6 textures provide static reference portraits. Runtime scales, particles and animation are not represented. Runicorn shows its default model; the optional alwaysChargers setting selects another model. Anima Stone uses an explicitly labeled unlit texture study to avoid ray-traced self-shadowing.

Models/textures by **Tslat and contributors**. Exact geometry/texture matches reuse existing preview URLs rather than duplicate image files. The evidence shown here remains 1.12.2-specific.
