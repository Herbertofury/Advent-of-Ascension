## The travel loop to preserve

Realm acquisition and portal activation lead into a realm’s terrain, encounters, resources, structures, progression and return travel. A dimension is complete only when that whole loop works. A registry key or a worldgen JSON is only one piece.

## Special cases

- **Nowhere:** distinguish legacy access restrictions from the newer arena/travel design. A legacy source file does not promise ordinary survival access.
- **Precasia:** record legacy and overhauled ecology, terrain, structures and travel acquisition separately. A modern screenshot must not illustrate a legacy guide without a label.
- **Overworld / Nether / End:** track AoA’s additions within vanilla dimensions separately from new dimensions. Vanilla ownership does not imply AoA content parity.
- **Ancient Cavern / Immortallis and other removed material:** historical archaeology lane. They are not silently covered by the 1.16.5 list; obtain era-specific evidence before declaring restoration.

## Every realm needs a dossier

Identity and source era; portal/key acquisition; entry conditions; generator/biomes; structures; mob/NPC/boss roster; resources and equipment; recipes/loot; hazards; time/weather/fog/audio; multiplayer travel; death/respawn; return route; chunk/save migration; full-resolution reference gallery; exact target build and test receipt.

The next authored realm dossiers should be prioritized by the active conversion dependency graph, not by which realm is easiest to make look complete. Unknowns stay visible.
