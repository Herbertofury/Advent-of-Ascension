# Trading and traders · 1.12.2

**Minecraft 1.12.2 · AoA 3.3.6.** Browse **363 candidate offer definitions across 59 NPC types** in the [illustrated Trading Desk](https://herbertofury.github.io/Advent-of-Ascension/trade-explorer.html?v=1.12.2). This historical system does not use the modern profession-level and merchant-XP fields shown for later releases.

The extractor checked 64 literal trader methods plus the separately decoded Undead Herald switch against released bytes and pinned source. Five banker EMPTY→EMPTY placeholders remain excluded. Herald contributes 22 realm-conditional definitions and four common offers; any resolved source context has four or five entries, not all 26. An empty placeholder is not a free item exchange.

## Plan a useful shopping trip

1. **Pick 1.12.2 before searching.** The 1.16.5 and 1.21.1 prices, pools and progression rules are separate data.
2. **Search for something you can sell or need to buy.** Item and currency names match both inputs and outputs. Metadata-sensitive fish are shown separately as Raw Fish and Raw Salmon.
3. **Choose a trader.** This release’s 22 Lottoman variants retain their own currency-specific definitions; they are not silently collapsed into the later shared pool.
4. **Bring both input stacks when shown.** A two-slot cost is additive. The Toy Merchant’s Smiley Upgrade Kit definition uses two stacks of 64 Circus Coins, not one alternative stack.
5. **Read special-stack requirements.** Ordinary fireworks or a superficially similar potion do not establish that the exact required stack matches.
6. **Check selection and use-limit behavior.** Candidate definitions are not guaranteed simultaneous offers. The legacy panel displays constructor use information rather than inventing a profession level or merchant XP.

## Generated pools and stock limits

The base trader seeds pool selection from its UUID. For a non-fixed pool of N candidates, the initial selection count is max(random nextInt(N), 1); the additional-trade counter can raise it up to N. Selected candidates are removed from the temporary pool, so the same pool entry is not picked twice. Fixed-list traders receive all candidates.

The default recipe constructor chooses five maximum uses for a stackable output and one for a non-stackable output. Some offers supply explicit values. However, the base use-recipe callback returns early for fixed lists or when the currently selected list already reaches the whole pool. Otherwise it increments uses and can expand/regenerate the list after all current offers are exhausted. A constructor max-use value is therefore not a universal restock timer or repeatability guarantee.

[Weapon purchase examples and the cannon upgrade chain](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Buying-Weapons-and-Trader-Upgrades-1.12.2) show the practical consequences for 29 weapon offers.

## Special offers worth reading carefully

### Explosives Expert: marked fireworks

The factory produces one Fireworks stack carrying Fireworks.Flight byte **42** and AoA boolean **true**. The trade definition exchanges that special stack for 50 Lunaver Coins, but explicitly starts with **uses = 1 and max uses = 1**. It is initialized at its use limit, not an ordinary repeatable currency payout. A runtime unlock or reset path has not been established here. The icon is a base firework picture and does not display those tags.

### Store Keeper: custom lingering potion

The factory starts from a Lingering Potion item and requests a Poison effect with **2500 ticks, amplifier 0, ambient true and particles true**. The duration is a construction argument, not a measured duration of every cloud application. Its required price is shown in the Trading Desk. The base bottle image does not certify the custom NBT or final tint.

### Spellbinders: enchanted books

The Primordial Spellbinder’s checked book offer is Silk Touch I; the Zal Spellbinder’s is Mending I. Their costs and enchantment labels remain attached to the distinct offers rather than being reduced to a generic enchanted-book icon.

### Smiley Upgrade Kit: two payment slots

The Toy Merchant requires **64 + 64 Circus Coins** and supplies an explicit one-use constructor limit, starting at zero uses. Keep both input slots distinct in any restored trading UI. Do not conflate this with the Explosives Expert’s already-at-limit definition.

## Pictures and version-safe navigation

The catalog uses 292 distinct item/metadata picture references: **275 existing atlas regions and 17 standalone source-model illustrations**. Six previously unmatched historical block models now have checked registration/localization entries in the general item index. Their trade cards link directly to those exact IDs.

Only the selected release’s compact data file is requested. The browser builds 24 cards at a time, caches loaded releases and ignores stale responses after a version switch. Atlas regions reuse the existing sheets; new standalone item and NPC images are lazy-loaded. No game-folder scan or background polling is performed. Vendor labels use a cached ID lookup instead of repeatedly scanning the vendor list for every card or search result. [Trade semantic and payload comparison](https://raw.githubusercontent.com/Herbertofury/Advent-of-Ascension/main/docs/trade-browser-compaction-proof-1.12.2.json) confirms that quantities, metadata, special requirements and use-limit fields were preserved.
