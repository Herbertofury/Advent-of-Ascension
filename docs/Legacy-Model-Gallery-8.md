## Coverage limits

The strict importer checks that every constructor addBox call and parent link was accounted for. 335 of 343 inspected Java model classes passed literal-constructor conversion; 301 also had a unique texture basename match and were rendered in this pass. The remaining classes, shared/variant textures, GeckoLib models, animation expressions, custom render scaling and runtime effects require separate adapters or validation. Do not silently treat a missing image as deleted content.
