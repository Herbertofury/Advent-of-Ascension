## Publication boundary

Upstream permits private modification but restricts public redistribution of modified code/assets. This repository contains original documentation, factual source inventories, reference links and source-derived visual/model references. Attribution is not an upstream license waiver. Publishing a merged code/artifact release requires the appropriate rights/permission evidence. A general project request does not establish an upstream license waiver.

## Known gaps

Desktop-only Enderloom changes are unverified in this pass. Earlier release history is not exhausted by branch-head snapshots. Source registration is not runtime availability; localization/data-file presence is weaker still. Detailed per-content stats, recipes, drops and authentic target galleries require continuing version-specific verification. Unavailable wiki pages are not silently replaced with unsupported claims.
