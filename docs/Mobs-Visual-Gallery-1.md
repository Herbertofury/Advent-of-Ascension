# Mobs Visual Gallery 1

[Visual atlas](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Visual-Atlas) · [Cross-version bestiary](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Bestiary)

Advent of Ascension models/textures by **Tslat and contributors**. These are independently rendered documentation showcases from **AoA 3.7.16.1 / Minecraft 1.21.1**, not Enderloom runtime screenshots. [Official mod](https://modrinth.com/mod/adventofascension) · [Official wiki](https://adventofascension.fandom.com/wiki/Advent_of_Ascension_Wiki).

Static rest poses include animals, monsters, bosses, NPCs and some miscellaneous entity resources. Models can remain in the archive after gameplay changes. Same-name mappings are resource previews, not proof that a renderer selects that texture in every state.
