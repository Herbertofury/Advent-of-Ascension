# Tommy family: three distinct magazine presentations

This is a visual game-design brief for `aoa3:tommy` and `aoa3:tiger_tommy`, not a real-world conversion guide or an implemented attachment package.

- **Requested main option:** a recognizable round, vertically oriented, under-mounted Tommy-style drum. New artwork is unfinished; the attempted Tiger Tommy edit produced no image.
- **Additional alternate:** a shallow, horizontal top-mounted pan, inspired by the DP-28/Lewis silhouette. A shared draft exists but is not selected because Tiger Tommy gained an erroneous third grip. The correction produced no image, so this option remains unfinished.
- **Preserved alternate:** the existing long box magazine, retained as a distinct selectable attachment concept rather than discarded.

Only one magazine presentation should be shown equipped at a time. Preserve Tommy’s wood/dark-metal identity and Tiger Tommy’s orange/black stripes and green eye. Do not transfer Tommy’s wooden grip onto Tiger Tommy or add extra handles. All native fitting, sight clearance, animation, resource behavior, persistence and compatibility remain unverified. No new capacity, reload rule or balance change is implied.
