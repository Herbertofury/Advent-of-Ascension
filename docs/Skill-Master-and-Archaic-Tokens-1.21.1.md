# Skill Master and Archaic Tokens · 1.21.1

**Minecraft 1.21.1 / AoA 3.7.16.1.** A practical route from Nowhere’s utility lobby to Skill Helmets and crystals. Prices, templates and reward definitions below were checked in the released archive. They are not a live-world or current Enderloom playtest.

## 1. Prepare your Nowhere entry

Use the [illustrated modern portal walkthrough](https://github.com/Herbertofury/Advent-of-Ascension/wiki/First-Portal-Walkthrough) for the frame and runes. The shipped shapeless Nowhere Realmstone recipe takes one each of:

- An accepted `c:shulker_boxes` item
- Nether Star
- Void Scales
- Recovery Compass
- Redstone Lamp
- Blank Realmstone

[Open the exact Nowhere Realmstone recipe](https://herbertofury.github.io/Advent-of-Ascension/recipe-explorer.html?v=1.21.1&q=aoa3%3Acrafting_shapeless_nowhere_realmstone). The shulker-box ingredient is a tag, so active pack membership matters. Use an empty box; this recipe listing does not establish preservation of stored contents. Keep your valuable storage separate.

## 2. Find the utility lobby

Once in Nowhere, use its **Utility** activity portal. The released activity enum supplies destination `(25.5, 1001.5, 16)` with yaw 90. These are code coordinates for that activity, not a suggestion to teleport blindly into an ungenerated or modified world. The normal Nowhere entry portal uses a different destination near `(25, 1501, 15)`.

The released utility-lobby structure and structure-set resources point to the utility start pool. Its 32 × 17 × 32 template contains one **`aoa3:skill_master`** at template-relative `(21.4366, 2.0625, 9.5611)`. That is the only Skill Master entity found in the scan of all **334** shipped AoA structure templates. Local template positions must not be mistaken for guaranteed world coordinates.

The NPC declares persistence in Nowhere and suppresses normal pushability there. Its damage guard preserves the bypass-invulnerability exception; “protected in Nowhere” does not mean absolutely indestructible under every command or mod.

One helmet costs **64 tokens at the base definition**. All six cost **384**. One of each crystal costs **74**. One of every listed output costs **458**. These are undiscounted shopping totals, not a promised final UI price.

The very large helmet stock value is the literal signed-int maximum, **2,147,483,647**; it is not a separate “infinite supply” guarantee. Merchant XP is merchant progression, not the player’s skill XP. [Read shared trading and restocking rules](https://github.com/Herbertofury/Advent-of-Ascension/wiki/Trading-and-Traders-1.21.1).

## 4. Earn tokens through parkour

The return-portal path checks that the player is alive, above the minimum build height, in the parkour region, touching an activity portal and associated with a course. It then grants that course’s optional reward table before moving to a next course or returning. Merely entering Nowhere, falling out, or visiting a course coordinate is not the checked completion path.

The tables below have a Nowhere dimension condition and one token entry per roll. Dexterity XP values are loot-function inputs, not a claim about the final skill gain after all modifiers.

| Tier | Shipped course record | Tokens per eligible reward roll | Dexterity XP input | Rolls to afford 64 tokens, best–worst bounds |
|---|---|---:|---:|---:|
| 1 | Ancient Hallways | 1–3 | 200–400 | 22–64 |
| 2 | Mine Madness | 3–8 | 500–750 | 8–22 |
| 3 | Twisted Treetops | 6–12 | 800–1,200 | 6–11 |
| 4 | Aurora | 10–16 | 1,500–2,500 | 4–7 |
| 5 | **No tier-5 course record found** | 14–20 | 3,000–4,500 | Availability unresolved |
| 6 | Nether Tourist | 19–28 | 5,000–7,500 | 3–4 |

**Important tier-5 gap:** six tier reward tables and six activity choices exist, but this archive contains only five course records: tiers 1, 2, 3, 4 and 6. The lookup returns failure when it cannot find a course. Do not plan on a usable tier-5 route solely because its reward table exists. This is a static completeness finding, not a reproduced in-game failure.

The roll bounds assume starting at zero tokens, successful eligible rolls and unchanged base tables. They are not average completion times or a promise that repeated attempts are safe, available or equally fast.

## 5. Boss-table token references

The `aoa3:worlds/nowhere_boss` table defines **15–25 tokens** with a Nowhere dimension condition. Eight shipped entity loot tables reference it:

- Elite King Bambambam
- Elite Nethengeic Wither
- Elite Smash
- Elite Tyrosaur
- King Bambambam
- Nethengeic Wither
- Smash
- Tyrosaur.

This establishes table-to-table references. It does not establish that every boss in every dimension drops tokens, nor does it replace checking the entity’s runtime loot binding, death eligibility, gamerules and modpack hooks. See [Drop Finder references](https://herbertofury.github.io/Advent-of-Ascension/drop-finder.html?v=1.21.1&q=aoa3%3Aarchaic_token).
