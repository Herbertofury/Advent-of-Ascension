# Buying historical weapons: traders and upgrades

**Minecraft 1.12.2 · AoA 3.3.6.** 29 checked weapon-output offers cover **25 weapons at 15 trader types**. These are trade candidates read from the released artifact, not promises that every NPC offers every row.

## Plan the purchase

1. Find the weapon below and bring every listed input. A second input is an additional cost, not an alternative.
2. Check whether the vendor uses a fixed list or a generated selection. A missing offer on one NPC does not prove that the weapon was removed.
3. Inspect the output quantity. For example, the Gorb Arms Dealer offers five Grenades for one Silver Coin; the Explosives Expert offers one for five Copper Coins. This does not establish a currency-conversion bargain.
4. For an upgrade, bring the old weapon too. The cannon chain is Mini-Cannon → Super-Cannon → Ultra-Cannon → Giga-Cannon, across different traders.
5. Open the linked usage guide before spending rare materials. Ammunition and weapon behavior are release-specific.

## Why a listed offer may be missing

The base trader seeds its selection from the NPC UUID. For a non-fixed pool of N candidates, the initial count is max(random nextInt(N), 1); an additional-trade counter can increase that count up to N. Candidates are removed as they are selected, preventing duplicate picks from that pool. Fixed lists include all candidates.

The base use-recipe method returns early for fixed lists or when the generated list already reaches the complete pool size. Otherwise it increments use counts; on the server, exhausting all current offers leads to an additional trade and regeneration. This is not a modern villager workstation/restock schedule, and reconnecting is not a documented reroll strategy.

The AoATraderRecipe constructor uses five maximum uses for a stackable output and one for a non-stackable output unless a constructor supplies an explicit limit. That constructor value alone does not determine depletion: the base use-recipe early-return rules still matter.
