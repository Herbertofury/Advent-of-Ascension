## Contents and operation

The source snapshot contains 2,362 canonical research records, 35 editorial study anchors, 10 recovered earlier picks, 2,340 records with archived creator media, 8,928 distinct image hashes, and 204 records with creator-linked direct videos. It includes standalone gun mods, content packs, integrations, artillery, Bedrock add-ons, plugins, datapacks, visual packs and older references. These are not 2,362 equally recommended standalone mods.

Search, structured queries, exact release-version/loader filtering, ecosystem/type/theme filters, cards/table/gallery, favorites, private notes, comparison, saved views, recent history, source attribution, theme switching, mobile layout and collection backup/import are implemented. Favorites and notes use browser-local storage; use export/import to move a collection between browsers or devices. The local-file and hosted-site storage origins are separate.

## Drive durability

The complete release is backed up in the user's existing AoA Weapon Production Toolkit, in the Minecraft Gun Atlas - Portable 2362 folder. The large ZIP exceeded the Drive transfer route's per-file boundary, so it was transported as six ordinary, independently extractable ZIPs. This changes packaging only: every original release file is present and matches its original SHA-256. No image, source file, Wiki page or test receipt was dropped.

`BACKUP-MANIFEST.json` records every path, file hash and owning ZIP. `PACKAGING-VERIFICATION.json` records full archive reconstruction checks. `REMOTE-VERIFICATION.json` records readback identity for all six uploaded ZIPs. Private Drive file IDs are retained in that private receipt rather than published here.

Extract all six parts into the same destination, then open `minecraft-gun-mods/index.html`. The permanent GitHub release also provides the entire archive as a single ZIP.

## Coverage and boundaries

The discovery ledger includes 38 Modrinth queries with terminal pagination and 23 CurseForge query attempts, 13 of which reached terminal pagination. Provider-limited gaps and unresolved sources are retained in the source ledgers rather than silently counted as absent. This is extensive finite public-source research, not a provable census of every private, unlisted or newly uploaded project.

Version/loader claims are tied to recorded release files. The work does not claim native Minecraft testing of every project, mutual compatibility, performance benchmarking, or full playback of every linked video. Modern, legacy and unofficial projects remain distinguishable.

## Continuity

Do not restart the completed research or overwrite personal collections on continuation. Reuse the canonical catalog, source ledgers, release identities and verification above. Further research should target documented provider gaps or sources changed after the recorded snapshot. No recurring refresh, hidden watchdog or automatic repatching was enabled for this delivery.
