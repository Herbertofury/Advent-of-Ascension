# Minecraft Gun Atlas

Open `index.html` beside `catalog.js`, `app.css`, `app.js` and the `assets` directory. The app works as a static GitHub Pages site and as an offline folder. No build service or account is required.

Favorites, notes and saved views are stored in this browser. Export a collection backup before moving devices. Import merges data and preserves unavailable project IDs. It does not write to the original spreadsheet.

## Reproducibility

`research.py` records source discovery; `collect.py` resolves project/release/media metadata; `catalog.json` is the canonical snapshot; `build.py` builds the portable explorer and Wiki pages; `qa/browser_test.py` exercises the real app. The four original UI source files are transported in a two-part checksum-verified bundle and are committed as normal source files after decoding.

Source timestamps are evidence freshness, not a compatibility guarantee. No Minecraft mod binaries are downloaded, installed or executed by this research pipeline. Creator media is attributed per project and is reference material, not redistributed mod assets.
