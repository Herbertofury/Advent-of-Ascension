## Organization

One flat Weapon Inspirations menu replaces recursive hub links and competing appended blocks. It contains Gaming weapons with Volume 2, Historical and experimental guns, Minecraft gun mods with Explore, TaCZ gunpacks with Rankings, and Creator-hosted discoveries. The hub provides one category table and clear explorer actions. The menu sits beside Visual collections, before the optional weapon-upgrade section.

The canonical owner is `docs/weapon_inspiration_navigation.py`. Parent-atlas, TaCZ, historical-gallery and expansion publishers all reuse this idempotent owner. Sparse worktrees load it from their exact Git HEAD. The inline historical publisher was repaired through the authorized connector. Re-publishing was tested and does not recreate the duplicate nesting.

Its public preview token was unavailable, so the entry has an explicit source-only fallback rather than a fabricated or broken image. The creator's future-content Barrett is not counted as released. No private file, purchased binary or paywalled attachment was fetched.

## Remote backup and reproducibility

GitHub provides one complete ZIP. Connected Google Drive preserves the same 19,384 file payloads in eight independently extractable ZIP parts under the existing AoA Weapon Production Toolkit's Minecraft Gun Atlas - Creator Discoveries folder. Every part was downloaded back and every original file's size and SHA-256 were checked. The old releases are preserved.

`BACKUP-MANIFEST.json` records all files and their owning parts. `REMOTE-VERIFICATION.json` retains the private remote IDs, exact hashes and readback proof in Drive. No private Drive identifiers are placed in this public record.

Extract the single GitHub ZIP, or all Drive parts into the same folder, then open `minecraft-gun-mods/index.html` or `minecraft-gun-mods/tacz/index.html`. Export/import transfers personal collections between hosted and offline browser origins.

## Recovery and continuation

The first live check found the previous Pages dataset because deployment had not completed. The exact failed job was rerun only after Pages run 40030942693 reported successful deployment; the dataset and acceptance tests were not weakened or re-researched. The final attempt passed the complete live and offline gates.

A content-only Action could not push workflow changes. The repair kept workflow edits in the authorized connector and made normal publishers load the shared owner from their own Git revision. No branch protections or token scope were broadened.

No further broad discovery or verification loop is needed for this release. Continue only with genuinely changed creator evidence, newly requested content or a reproducible defect, preserving these identities and the user's saved collections.
