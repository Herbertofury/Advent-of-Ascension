## Durable backup and use

GitHub provides one complete ZIP. Connected Google Drive preserves the same 20,181 file payloads in eight independently extractable ZIPs under the existing AoA Weapon Production Toolkit's Minecraft Gun Atlas - TaCZ Hidden Gems folder. Every part was downloaded back; every restored file's bytes, size and SHA-256 were compared with the permanent complete release. Earlier releases and coherent source checkpoints remain preserved.

`BACKUP-MANIFEST.json` maps all files to their parts. `REMOTE-VERIFICATION.json` stores the exact private Drive IDs, readback hashes and publication receipts in Drive; no private Drive identifier is placed in this public document.

Extract the single GitHub ZIP, or all Drive parts into one directory, then open `minecraft-gun-mods/index.html` or `minecraft-gun-mods/tacz/index.html`. Both work without a local server. Export/import transfers personal collections between hosted and offline browser origins.
