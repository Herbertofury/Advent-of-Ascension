# Reading routes and local checklists

The [walkthrough library](https://herbertofury.github.io/Advent-of-Ascension/tutorials.html) now offers a six-stop reading route for each checked release. Choose the release first; the checklist follows that version.

## What the marks mean

- Check Read after you have reviewed a guide. The counter tracks reading only, not quests, boss kills or Minecraft save progress.
- Checkmarks are stored only in the current browser, separately for each release. They are not sent to a game, server or user account.
- Clear this reading checklist clears the currently selected release’s marks. Other releases keep their marks.
- If browser storage is blocked, the checklist still works for that page session and displays a storage notice. Closing or reloading can lose those unsaved marks.
- Sharing a walkthrough URL shares its release/search filters, not your checkmarks.
- Searching or choosing a goal temporarily hides the reading route so results stay focused. Clear those filters to return to the route.
- The **Compare all indexed releases** option and unsupported versions have no mixed or substituted checklist. Choose one supported release.

## Why 1.20.1 is labeled preparation

Its route starts with the checked portal/support limits and dimension reference. It does not pretend that every historical realm or complete progression chain is playable in that release. Food, drops, armor and weapon references follow those checks.

## Accessibility and loading

The checklist uses native labeled checkboxes, a clear-reading button, visible keyboard focus and a live text counter. The route data are included in the existing page; no extra data fetch is required. Guide lookup is indexed once, and typing a search does not rebuild the unchanged route. Actual browser QA and documentation tests are separate from in-game testing.
