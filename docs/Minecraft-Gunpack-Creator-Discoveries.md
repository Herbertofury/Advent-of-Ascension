## Paid creator-hosted reference: Bedrock, not TaCZ

Public preview not archived; use the exact creator source.

**[AEG-Tactical](https://www.patreon.com/Fission_TrackStudio/posts/aeg-tactical-for-159166702) by Fission_Track Studio.** A creator-hosted Bedrock firearm add-on with tactical models and aiming/reload animation. It is a separate paid reference, not a Java TaCZ gunpack.

**Paid creator release (buyout access).** The public description lists Bedrock 1.21.90+; select the purchased build matching your game. Native compatibility has not been tested. The creator says the boots armor slot is used. Check the equipment limitation before buying.

The creator marks a pictured Barrett as future content; it is not presented here as an included firearm. Prices and access can change, so the listing links to the original purchase page rather than quoting an expired promotion.
